# 2018-Memorial-Sloan-Kettering-Breast-Cancer-Study
🧬 Analyzing breast cancer genomic data from MSKCC using ML. Random Forest (85% accuracy), SVM (83%) and Naive Bayes models predict survival from mutation profiles. Identified key genes (TP53, PIK3CA) and novel interaction patterns. Open-source implementation enables reproducibility. 🤖 #MachineLearning #CancerGenomics
